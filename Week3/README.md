# Week 3: Visual Playlist Link

An interactive web sculpture made from clickable text links. The links are placed around the page to form groups inspired by everyday objects, such as books, coffee, a clock, and heels. Each link opens a related webpage in a small popup window.

### How It Works

The page uses ` p5.js`  to place each link at its set position. When a link is clicked, its URL opens in a popup window.

### How to Use

Open `index.html` in a browser and click the link labels. Allow popups in the browser if they are blocked.

### Files

- `index.html` 

This file contains the links, their positions, and the popup code.
